A one-line review of planet Earth written by an alien tourist, for the make.fun bounty "Alien Field Notes: The Two Day Earth Review". The program writes the review as plain text to `/output/entry.txt` (at most 200 characters).

## Entry

```
Tasted the ocean: endless salty soup, and the locals swim in it on purpose. Baffling, beautiful planet. 4/5, would come back.
```

## Run

```sh
node main.ts
```
